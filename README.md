# UI-автотесты главной страницы сервиса путешествий

Пет-проект по автоматизации тестирования веб-интерфейса (UI) с использованием паттерна POM

## Стек технологий
* **Язык:** Java 17
* **Сборка:** Maven
* **Тестовый фреймворк:** JUnit 5
* **Автоматизация браузера:** Selenium WebDriver

## Структура проекта
* `src/main/java/.../pages` — Page Object классы с локаторами и методами страниц
* `src/test/java/.../tests` — тестовые сценарии 

## Запуск тестов
```bash
git clone https://github.com
cd MyProject/Autotests
mvn clean test
```
